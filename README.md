# One Lane Left Privacy Policy

This repository hosts the public privacy policy for One Lane Left, published by Dan-Mihai Balean.

- Android package: `com.baleandanmihai.onelaneleft`
- iOS bundle: `com.baleandanmihai.onelaneleft.ios`
- Public support and privacy contact: balean.danmihai.dev@gmail.com

The GitHub Pages root displays the policy directly. `privacy-policy.html` is retained as an identical alternate named copy. The policy describes direct Google AdMob/UMP, optional Unity Analytics, platform-native Google Play and Apple StoreKit purchases when enabled, and local game data. App availability depends on the released version.
